# 「テーマの近接」を UI 要件として決める

**前提**: なし ／ **担当**: 人間 ／ **参照**: `CLAUDE.md` 目的、`docs/plan.md` §3、§5

## 目的
`CLAUDE.md` はこの器の目的を「どの場所・どの時代の話か、**どのテーマと近接するか**を一望できる」と書いているが、`docs/plan.md` §3 の UI 構成に近接を見せる仕掛けが無い。
地図上の距離と era スライダーで暗黙に見えるという想定なのか、明示的な機能が要るのかで S4・S5 の範囲が変わる。
目的と設計の乖離は S8 で README の設計判断を書く段になって効いてくるので、その前に潰す。

## 作るもの（決定と文書の改訂）
- **暗黙で満たすと決める**か、**明示的な機能を足す**かの判断
- 足すなら中身 — 選択中テーマと era が重なる他テーマの強調、`tags` / `region` での関連一覧、など
- 足すなら置き場所 — S4 か S5 のどちらへ入れるか、あるいは新しいステップを立てるか
- `docs/plan.md` §3 へ近接についての立場を明記。ステップを増やすなら §5 の順序の地図も改訂
