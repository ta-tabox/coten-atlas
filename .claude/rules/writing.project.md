# 文章とコミットの規約のうち coten-atlas だけの規則

`writing.md`（共有の雛形とバイト一致させる配布物）に加えて読み込まれる。
雛形からの逸脱と追加だけを持ち、`writing.md` は書き換えない。

- **各シリーズの典拠のファイル（`docs/sources/<シリーズ id>.md`）は、当てた規則の ADR を経緯として指してよい**（「md の持ち場」の ADR を指さない項からの逸脱）
  典拠のファイルは値を決めた根拠の記録で、作業のたびに読まれていまの状態を持つ文書に当たらない
- **`docs/ARCHITECTURE.md` §8「持ち越した開いた問い」は、現況の文書の中で構造に関わる未決を持ち、未決を解く open の issue の番号を置いてよい**（「md の持ち場」の現況の文書の項と issue 番号の項からの逸脱）
  作業単位にならない構造の未決は issue に置けず、このリポジトリは申し送りの層も持たないので、§8 のほかに置き場が無い（経緯は `docs/adr/0025-retire-next-md.md`）
  閉じた issue の番号は §8 からも消す
