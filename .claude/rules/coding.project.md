# コーディング規約のうち coten-atlas だけの規則

`coding.md`（共有の雛形とバイト一致させる配布物）に加えて読み込まれる。
雛形からの逸脱と追加だけを持ち、`coding.md` は書き換えない。

- **比喩は、使う場所で解けるときだけ使う**
  定義が同じ節にあるなら可、別のファイルにあるなら不可、どこにも無いなら不可
  読み手はその語を解く鍵を持っていないので、書き手にとっての短さが読み手にとっての遅さになる（#73）
- **欄（props・interface・型・zod スキーマの欄）・定数・型の JSDoc に、名前と型を日本語へ言い換えただけの文を書かない**（`coding.md`「コメント」節への追加）
  判定は「その文の情報が、付いている宣言の名前・型・シグネチャからすべて復元できるか」
  悪例は `onClose: () => void` に「閉じるボタンが押されたときに呼ぶ」、`series: Series` に「開いているシリーズ」
  名前と型に無い情報（並び順・キー・欠損時の値・単位・誰が作って誰へ渡すか）を足せないなら、JSDoc ごと書かない
