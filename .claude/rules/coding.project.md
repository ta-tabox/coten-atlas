# コーディング規約のうち coten-atlas だけの規則

`coding.md`（共有の雛形とバイト一致させる配布物）に加えて読み込まれる。
雛形からの逸脱と追加だけを持ち、`coding.md` は書き換えない。

- **比喩は、使う場所で解けるときだけ使う**
  定義が同じ節にあるなら可、別のファイルにあるなら不可、どこにも無いなら不可
  読み手はその語を解く鍵を持っていないので、書き手にとっての短さが読み手にとっての遅さになる（#73）
