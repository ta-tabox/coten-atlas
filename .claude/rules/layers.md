# 置き場と依存の向き（リポジトリの表）

`coding.md`「置き場と依存の向き」の規則を、このリポジトリの実在するモジュールに当てた表。
上の `paths` に当たるファイルを Read した時点で読み込まれる。
雛形は骨格しか持たない。
初回の実装セッションで、実在するモジュールの名前で各表を埋め、無い表は落とす。
現況の文書（`docs/ARCHITECTURE.md` 等）は、境界の禁止則を「正は `.claude/rules/layers.md`」の一行で指す。

## 境界を閉じるモジュール

| 境界 | 閉じるモジュール | 他のモジュールが受け取るもの |
|---|---|---|
| （DB） | （`lib/db.ts`） | （ドメイン型の値） |
| （環境変数） | （`lib/config.ts`） | （解決済みの設定） |
| （ネットワーク） | （`lib/ai/anthropic.ts`） | （検証済みの応答） |
| （ファイル） | （`lib/catalog-dir.ts`） | （スキーマを通した値） |
| （DOM） | （`components/*.tsx`） | （数値・文字列） |

## 層と、import してよい相手

| 層 | 置き場 | import してよい相手 | 持つもの |
|---|---|---|---|
| （ドメイン型） | （`lib/types.ts`） | （無し） | （型だけ） |
| （純粋な計算） | （`lib/*.ts`） | （ドメイン型・同じ層） | （関数とテスト） |
| （境界） | （上の表） | （純粋な計算・ドメイン型） | （境界の道具と検証） |
| （配線） | （`app/**`・`scripts/*`） | （境界・純粋な計算） | （受け取り・呼び出し・出力） |

| （選択中の項目） | （親コンポーネントの state） |
