# デザイン規約（UI に触るとき）

上の `paths` に当たるファイルを Read した時点で読み込まれる。
ここに置くのは**従わせる規則**だけで、「なぜこの見た目か」の決定と経緯は `docs/adr/` が持つ。
現況の記述（画面構成・コンポーネントの一覧）は `docs/ARCHITECTURE.md` の担当で、ここへ複製しない。
雛形は骨格しか持たない。
見出しはリポジトリで使うものだけ残し、各項はリポジトリの初回 UI セッションで決めたことを書く。
規則は「〜する」の形で書き、禁じる形で残すのは走査して拾わせたい禁止則だけにする。
