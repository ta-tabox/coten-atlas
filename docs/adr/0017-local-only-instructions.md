# 0017. 手元の環境にだけ意味を持つ指示と申し送りは追跡しない

- **状態**: 採用
- **決定日**: 2026-08-29
- **関係する ADR**: 0011

## 文脈

このリポジトリは公開する（0011）。
ところが `CLAUDE.md` をはじめとする文書は、作者の手元にある別のディレクトリ群を前提にした語彙と参照を持っていた。
その語彙は手元に置かれて初めて解けるので、GitHub から読む人には解けない。
参照の側はもっと悪く、公開したリポジトリから辿れないパスがリンクとして残る。

`NEXT.md` はその最大の発生源だった。
中身は次のセッションへの申し送りで、外の読み手に効く情報をほとんど持たない。
加えて実害があった。
worktree を並べて複数の作業を同時に進めると、全員が同じファイルの同じ辺りへ書くのでコンフリクトが常態化する。

`docs/adr/` の本文にも同じ語彙が入っていた。
ここは追記のみで本文を一字も削らない規約（`README.md` 規約 4）なので、可変な文書だけを直すと語彙が二つに割れる。

## 決定

**手元の環境との接続は `CLAUDE.local.md` が持ち、追跡しない。**
置き場はリポジトリのルート。
Claude Code は cwd とその上の全ディレクトリから `CLAUDE.md` と `CLAUDE.local.md` を読み、後者を前者の後ろへ連結する。
`CLAUDE.md` の側に参照の一行を置く必要が無いので、**公開するファイルに痕跡が一つも残らない**。

**`NEXT.md` を追跡から外す。**
ファイルの実体は手元に残し、`.gitignore` へ入れる。
公開する側の申し送りは GitHub Issues と `ROADMAP.md` が持つ。

**公開するファイルからは、手元でしか解けない語彙を落とす。**
`docs/adr/` の本文もこの一度に限り書き換える（規約 4 の明示的な例外。適用範囲は語彙の置き換えのみで、決定・理由・帰結は動かさない）。

## 理由

**痕跡が残らないのが `CLAUDE.local.md` を採る理由。**
`CLAUDE.md` からの `@` import でも読ませることはできるが、import 行そのものが公開されるので目的を半分しか満たさない。

**worktree からも読める。**
worktree は `<ルート>/.claude/worktrees/<名前>` に作るので、ルートは worktree の祖先に当たる。
公式ドキュメントは「gitignore された `CLAUDE.local.md` は作った worktree にしか存在しない」と注意しており、リポジトリの外に worktree を置く構成では回避策が要る。
ここでは要らないことを実測で確かめた（ルートに置いた印を worktree からツール無しのセッションに問い、退避すると消え、戻すと再び読めた）。

**コンフリクトが消える。**
`NEXT.md` を追跡から外すと、並列の worktree が同じファイルを奪い合わなくなる。
失うのは公開時の開発ログだが、それは issue が既に持っている。

### 採らなかった案

- **`@~/.claude/…` の import で手元の指示を引く。** 公式ドキュメントが worktree の回避策として挙げる形だが、import 行が公開ファイルに残る
- **公開向けの用語集を置いて、消すのでなく解けるようにする。** 消せない箇所への次善にはなるが、`CODING.md` が持つ判定（比喩の定義が別ファイルにあるなら不可）に正面から反する。読み手に一段の参照を強いる形を、規約の側で禁じたばかりだった
- **`NEXT.md` を公開したまま、語彙だけを直す。** コンフリクトの実害が残る。書くたびに公開を意識する固定費も乗る
- **公開が要る「今後の予定」を README へ切り分ける。** `ROADMAP.md` が既に順序と閾値を持つので、二つ目の予定表を作ると同期の義務が生まれる
- **worktree を作るたびにシンボリックリンクを張る手順にする。** 実測の前はこれを採る方針だった。`SessionStart` フックでは間に合わない（指示ファイルはセッションの起動時に読まれるので、後から張ったリンクは次の回からしか効かない）ため、人間の手順として残すことになる。祖先から読めると分かった以上、手順そのものが要らない

## 帰結

- **`CLAUDE.local.md` が無い環境では、手元の接続だけが落ちる。** 公開する側の規約（git・ハーネス・文書の層）は `CLAUDE.md` に残るので、リポジトリ単体でも作業はできる
- **`--setting-sources` から `local` を外すと `CLAUDE.local.md` は読まれない。** 既定では読まれる
- **`NEXT.md` は `git log` から消える。** 過去のコミットには残るが、以後の申し送りは追跡されない
- `docs/adr/` の本文が一度だけ書き換わった。`README.md` 規約 4 にこの例外を記した
- 公開するファイルに残る語彙は、外から読んで解けるものだけになった

## 覆る条件

worktree をリポジトリの外へ置く構成へ変えたとき。
祖先から読める前提が崩れるので、置き場と配り方をやり直す。

このリポジトリを非公開へ戻したとき。
分離の理由が消えるので、`CLAUDE.md` へ畳み直してよい。
