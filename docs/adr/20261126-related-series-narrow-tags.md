# 関連シリーズ行は、狭い主題のタグを共有するシリーズだけを並べ、`region` を判定に使わない

- **状態**: 採用
- **決定日**: 2026-11-26（#140）
- **関係する ADR**: 20261126-series-vocabulary-region-as-label（`region` を地域の表示として理由づけ直す）、20260911-series-vocabulary-without-kind（20261126-series-vocabulary-region-as-label が supersede した）

## 文脈

`docs/ARCHITECTURE.md` §4 は、関連シリーズ行に「`tags` を共有するか `region` が同じ」シリーズを並べると決めていた。
`catalog/series.json` の 68 件にこの条件を当てると、吉田松陰 → 伊藤野枝（`思想` と日本）、ヒトラー → フリードリヒ大王（`戦争` とヨーロッパ）、フランス革命 → フリードリヒ大王（`政治`・`思想` とヨーロッパ）のように、聞き手が近いと読まない組が並んだ。
主題のタグのうち `戦争` は 26 件、`政治` は 18 件、`宗教` と `帝国` は 13 件、`思想` は 11 件が持ち、次に多い `技術` は 5 件である。
`region` が同じことは、地図の上で点が近いことと同じ情報になる。

## 決定

| 判定の材料                                       | 扱い                                                           |
| ------------------------------------------------ | -------------------------------------------------------------- |
| 種別のタグ（`人物`・`集団`・`出来事`・`概念史`） | 数えない                                                       |
| 多くのシリーズが持つ広い主題のタグ               | 名指しで列挙し、数えない                                       |
| 残りの主題のタグ（狭いタグ）                     | 一つでも共有すれば関連とみなし、共有する数の多い順に並べる     |
| `region`                                         | 使わない                                                       |
| `timeRange`                                      | 共有するタグの数が同じシリーズを、年代の近い順に並べるのに使う |

並べる件数には上限を置き、関連するシリーズが無ければ行ごと出さない。
決定時点の広いタグは `戦争`・`政治`・`宗教`・`帝国`・`思想` の 5 語で、上限は 4 件である。
広いタグの現況は `web/src/lib/schema/series.ts`、上限の現況は `web/src/lib/map/related-series.ts` が持つ。

## 理由

- **多く並べることを目的にしない** — 近いと読めない組が 1 件混ざるだけで、行の全体が当てにならなく見える。0 件の行を出さないほうが害が少ない
- **`region` を外す** — 地理の近さは地図が既に示すので、関連シリーズ行が同じことを二度言うだけになる
- **広いタグを件数のしきい値でなく名指しで除く** — しきい値はシリーズが増えるたびに、どの語が広いかを黙って入れ替える。名指しなら、結果が変わるのは人がリストを直したときだけになる
- **種別のタグを数えない** — `人物` は 42 件が持ち、共有しても主題の近さを言わない

### 採らなかった案

| 案                                                        | 採らなかった理由                                                                                                                                       |
| --------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 種別のタグを後ろで比べ、`region` を残して順に並べる       | 吉田松陰 → 伊藤野枝、ヒトラー → フリードリヒ大王のように、広いタグと地域だけを共有する組が 4 件の中に残る                                              |
| `region` を外し、タグを持つシリーズが少ないほど重く数える | フランス革命 → フリードリヒ大王が残り、吉田松陰の 4 件目が `教育` だけのエリザベス・ブラックウェルに替わるだけで、広いタグの一致が並ぶ構造は変わらない |
| 年代が重なるシリーズに限る                                | ヒトラー → 高杉晋作、ガンディー → 天皇のように、広いタグだけを共有する同時代の組がかえって前に出る                                                     |
| 広いタグをタグを持つシリーズの件数のしきい値で決める      | いまの 68 件では名指しと同じ結果になるが、シリーズを足すたびに境目の語が黙って入れ替わる                                                               |
| シリーズ間の関連を人手で張る欄を足す                      | 全シリーズへ人手で張る費用が要り、スキーマも増える。管理画面で張る形は別に検討する                                                                     |

## 帰結

- 68 件のうち 32 件は関連シリーズが 0 件になり、行を出さない
- `region` を読む画面は、詳細カードの地域の表示だけになる。`region` を閉じた集合にする理由は [20261126-series-vocabulary-region-as-label](20261126-series-vocabulary-region-as-label.md) が地域の表示として持ち直す
- 主題のタグを新しく足すときは、多くのシリーズへ付く語かを判じ、そうなら広いタグの列挙にも足す

## 覆る条件

- 広いタグを除いても、聞き手が近いと読まない組が並ぶと分かったとき
- 関連を人手で張る仕組み（管理画面など）を入れ、タグの一致に頼らなくてよくなったとき
- `tags` の語彙を細かく割り直し、`戦争` のような広い語が無くなったとき
