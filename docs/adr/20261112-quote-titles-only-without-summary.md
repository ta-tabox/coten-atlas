# 引用は題号に限り、説明文・ロゴ・カバーアートに触れず、シリーズは独自の説明の欄を持たない（20260823-quote-titles-only を supersede）

- **状態**: 採用
- **決定日**: 2026-11-12
- **関係する ADR**: 20260823-quote-titles-only（これを supersede する）、20260827-license（データのライセンス）

## 文脈

20260823-quote-titles-only は、番組から引用するのを題号に限り、番組の説明文の代わりに置いたシリーズの `summary` を「残すが当面は空」とした。
シリーズは 67 件に増えたが、`summary` を書いたシリーズは 1 件も無い。
詳細カードは `summary` が空文字なら段落を出さないので、欄はデータの形にだけ残り、画面には出ていない。
`summary` を書くには、各シリーズに番組の説明文を写さない一文を人間が書き、説明文と似ていないかを確かめる作業が要る。

番組公式に第三者向けの利用規約が無く、引用の線を原則から引く事情は 20260823-quote-titles-only の時点から変わっていない。

## 決定

- **引用の範囲**: シリーズ名とエピソードタイトルのみ載せ、番組の説明文は引かない
- **シリーズの説明**: シリーズは独自に書く説明の欄を持たない
  詳細カードがシリーズについて独自に出すのは、データが持つ年代や場所などの構造化した値に限る
- **番組名と画像**: 番組名はテキストとしてのみ使い、ロゴ・カバーアート・出演者画像は使わない
- **表記**: 非公式である旨・権利の帰属・地図上の整理は独自である旨・公式への導線の4点を、フッタ（短文）と README と `/about` に置く
- **公式への導線**: 番組公式 `https://coten.co.jp/services/cotenradio/` への導線は、配信リンクとは別にフッタへ常時置く

## 理由

- 番組公式に第三者向けの利用規約が無く（`crew-terms-of-service` は有料会員向けの契約で非会員には及ばない）、許諾も禁止も明示されていないので、著作物性が争いになりにくい題号だけを載せる
- ロゴは出所表示なので、使うと公式・提携との誤認を招く
- 番組サイト `cotenradio.fm` はドメインが失効して第三者の広告サイトに変わっているので、公式への導線の宛先は運営元 COTEN の COTEN RADIO ページにする
- 値の入らない欄をデータの形に残すと、読み手は書かれる予定の値があると読み、消費側は空文字の分岐を持ち続ける
- このリポジトリは恒久運用を前提にしないので、シリーズを足すたびに一文を書いて説明文との類似を確かめる手間に見合わない
- シリーズの中身はエピソードの題号の一覧が既に示している

採らなかった案:

- **シリーズごとに独自の一行説明を書く** ／ 全シリーズ分の文を書く作業と説明文との類似の確認が人間に乗り、シリーズを足すたびに同じ作業が要る
- **`summary` を空文字のまま残す** ／ 値を一つも持たない欄が、スキーマと詳細カードの分岐に残り続ける

## 帰結

- `catalog/series.json` の各シリーズから `summary` の欄が消え、スキーマは `summary` を未知のキーとして拒否する
- 詳細カードは `summary` の段落を持たない
- カバーアートを使わないので、シリーズの視覚的な差は地図上の図形のスタイルだけで付ける
- 20260827-license がデータの独自価値に数える `summary` は、データから消える

## 覆る条件

番組公式が第三者向けの利用規約を出したとき、あるいは個別に許諾を得たとき。
または、シリーズごとの説明文を書き続ける担い手を置くと決めたとき（独自の説明の欄を戻す）。
