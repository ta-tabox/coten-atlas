# 0008. 引用は題号に限り、説明文・ロゴ・カバーアートに触れない

- **状態**: 採用
- **決定日**: 2026-08-23（#17。導線の差し替えは 2026-08-25）
- **関係する ADR**: 0006（配信リンク）

## 文脈

この器は番組の非公式なファンサイトとして公開する。
番組公式に第三者向けの利用規約が無い状態で、どこまで引くかの線を引く必要がある。

## 決定

シリーズ名とエピソードタイトルのみ載せ、番組の説明文は引かない（`summary` は残すが当面は空）。番組名はテキストとしてのみ使い、ロゴ・カバーアート・出演者画像は使わない。非公式である旨・権利の帰属・地図上の整理は独自である旨・公式への導線の4点を、フッタ（短文）と README と `/about` に置く。番組公式 `https://coten.co.jp/services/cotenradio/` への導線は配信リンクとは別にフッタへ常時置く。文言の実装は S8。

## 理由

番組公式に第三者向けの利用規約が無く（公開ページを全列挙して確認。`crew-terms-of-service` は有料会員向けの契約で非会員には及ばない）、許諾も禁止も明示されていないので、線は原則から引くしかない。著作物性が争いになりにくい題号だけを載せ、説明文と画像には触れない。ロゴは出所表示なので公式・提携との誤認を招く。番組サイト `cotenradio.fm` はドメインが失効して第三者の広告サイトに変わっており、公式への導線に使うと誤誘導になるので、宛先は運営元 COTEN の COTEN RADIO ページにする（#13 で確認、差し替え日 2026-08-25）。

## 帰結

- `themes.geojson` の `summary` は自前の要約であって番組の説明文の引き写しではない
- カバーアートを使わないので、テーマの視覚的な差はスタイル（`kind`）だけで付ける
- フッタ・README・`/about` の4点表記は公開と同時に要る（S8。実装は #25）

## 覆る条件

番組公式が第三者向けの利用規約を出したとき、あるいは個別に許諾を得たとき。
