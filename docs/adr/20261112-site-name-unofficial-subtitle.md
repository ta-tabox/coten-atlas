# 公開画面の名前を COTEN RADIO MAP にし、非公式であることを示す副題と常に対で出す

- **状態**: 採用
- **決定日**: 2026-11-12
- **関係する ADR**: 20261112-public-screen-layout-and-style（名前と一文は上端の帯に載る）、20260823-quote-titles-only（番組からの引用は題号に限り、ロゴとカバーアートを使わない）、20260827-license（表記の全文は `/about` が持つ）

## 文脈

決定日の公開画面には、サイト名が出ていなかった。
名前は `title`・README の見出し・リポジトリ名・公開 URL の basePath に `coten-atlas` として在るだけだった。
`coten` は制作元の社名で、`atlas` は日本語の読み手には意味が伝わりにくい。
非公式のファンサイトであることは、`/about` の本文にだけ書いてあった。

20261112-public-screen-layout-and-style が、名前と何のサイトかの一文を画面上端の帯に常に出すと決めた。
スマホの幅では一文を省き、名前とリンクだけを一行に収める。

## 決定

| 対象             | 決定                                                                                                         |
| ---------------- | ------------------------------------------------------------------------------------------------------------ |
| 名前             | `COTEN RADIO MAP`                                                                                            |
| 名前を使う面     | 画面に出る名前のすべて（上端の帯・`title`・OGP・`/about` の `title`）                                        |
| 名前を変えない面 | リポジトリ名と公開 URL の basePath（`coten-atlas` のまま）                                                   |
| 非公式の表示     | 上端の帯では、名前のすぐ下に非公式のファンサイトであることを示す副題を組み、名前と副題を一つの表題として出す |
| 幅による省略     | 名前と副題はどの幅でも省かない。省いてよいのは一文だけ                                                       |

副題と一文の文言の現況は、上端の帯の実装が持つ。

## 理由

- 番組名を含む名前は、番組を知る人にはすぐ何のサイトかが伝わり、社名だけの `coten` より意味が通る
- 番組名を含む名前は番組公式のサービスと取り違えられうるので、非公式であることを名前と同じ表題の中で示す
- 副題を名前の下へ組めば、スマホの一行の帯でもリンクを削らずに収まる
- リポジトリ名と URL を変えると、公開済みの URL と basePath と GitHub Pages の置き場がすべて動く

| 採らなかった案                                             | 採らなかった理由                                               |
| ---------------------------------------------------------- | -------------------------------------------------------------- |
| `coten-atlas` のまま                                       | 社名と英語の語の組で、日本語の読み手に何のサイトかが伝わらない |
| 日本語名（コテン地図帳）                                   | `コテン` が社名のままで、番組との関係が名前から読めない        |
| 非公式を枠付きの札で名前の横に出す                         | 札の形が警告に見え、地図帳調の表題に合わない                   |
| 非公式を一文の末尾にだけ書く                               | スマホの幅では一文を省くので、非公式であることが画面から消える |
| 名前の横に灰色の添え字で一行に並べる                       | 390px の幅でリンクが画面の外へはみ出る                         |
| 名前を帯にだけ使い、`title` と OGP は `coten-atlas` のまま | URL を貼った先のプレビューと画面とで名前が食い違う             |

## 帰結

- 上端の帯の実装は、名前と非公式の副題を一つの表題として描き、どの幅でも両方を出す
- `title` と OGP は `COTEN RADIO MAP` を名前に使う
- README の見出しとリポジトリ名 `coten-atlas` の関係は、README の冒頭を書く作業が決める

## 覆る条件

- 制作元の COTEN から、番組名を名前に使うことへの申し入れがあったとき
- 番組公式から認められ、非公式の表示が事実と合わなくなったとき
- 番組名が変わったとき
