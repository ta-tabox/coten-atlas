# 0034. 手で書く欄の語彙を決め、`region` は地図の区画・`tags` は種別と主題だけを持つ

- **状態**: 採用
- **決定日**: 2026-09-07（#101）
- **関係する ADR**: 0008（引用は題号に限る）、0018（割当キーを `itunes:season` にする）、0023（`kind` は geometry から導けない差だけを持つ）、0026（位置情報の段階分け）、0027（シリーズと事物の分離）、0035（歴史の裏どりを `@historian` の別レーンに分ける）

## 文脈

`series.json` の 66 件のうち 56 件を、#101 から #106 までの 6 つの issue が別々のセッションで書く。
`id`・`title`・`region`・`tags` は人手で書く欄なので、規則が無ければ 6 通りの語彙ができる。

`ARCHITECTURE.md` §4 は関連シリーズ行を「`tags` を共有するか `region` が同じ」で選ぶと決めている。
`region` は等値で照合する鍵なので、揃っていない値は「近くない」と同じ結果を返す。
関連シリーズ行が空になるだけで、壊れ方が画面に出ない。

先に書かれた 10 件が既に揃っていない。
`region` に `日本`・`ギリシア`・`ユーラシア`・`地中海〜西アジア` が同居し、`tags` は `["人物", "幕末", "日本"]` のように種別・時代・地域が同じ配列に入っている。

## 決定

### 欄ごとの規則

| 欄 | 規則 |
|---|---|
| `id` | シリーズ名の読みをローマ字にする（下の「`id` の表記」） |
| `title` | 番組内のコーナー名の接頭辞（`ショート`・`ジンブンガク`）を除く。除いた事実を `tags` にも持たせない |
| `kind` | 主題そのものが土地に在れば `place`、無ければ `concept`。**`place` と `ANCHOR_UNLOCATED` は組まない** |
| `region` | 下の 13 値から 1 つ。そのシリーズが扱う地理の広がりを表す欄で、`anchor` とは独立に決まる |
| `tags` | 種別を最低 1 つ、主題を 0 個以上。合わせて 4 個以内 |

この語彙を既存の現物にも当てる。
旧い規則のまま残す例外を作らない。

### `region` の 13 値

`日本` / `朝鮮半島` / `中国` / `東南アジア` / `南アジア` / `中央ユーラシア` / `西アジア` / `アフリカ` / `ヨーロッパ` / `北アメリカ` / `南アメリカ` / `オセアニア` / `地域なし`

**一覧はここで閉じる。**
値を足すときは新しい ADR を書く。

区画は重ならず、時代と結びついた名（`地中海`）を使わない。

### `region` の選び方

| 状況 | 値 | 例 |
|---|---|---|
| 区画が一つに決まる | その区画 | 秦の始皇帝 → `中国` |
| 複数に跨るが本拠（出自・活動の中心・帰る場所）が一つある | 本拠の区画 | アレクサンドロス → `ヨーロッパ` |
| 跨りが対等で本拠が無い | `地域なし` | 世界三大宗教 |
| 位置なしだが広がりが一区画に収まる | その区画 | ショート 切腹 → `日本` |

座標が二つの区画に読める継ぎ目。

| 継ぎ目 | 区画 |
|---|---|
| ロシア | ウラル山脈以西は `ヨーロッパ`、以東は `中央ユーラシア` |
| 北アフリカ（エジプトを含む） | `アフリカ` |
| アナトリア | `西アジア`（イスタンブールの欧州側も含め、トルコを割らない） |
| モンゴル高原・中央アジア | `中央ユーラシア`（チベットと満洲は `中国`） |
| メキシコ・中米・カリブ | `北アメリカ` |

### `tags` の種別（最低 1 つ。複数当てはまれば複数）

| 値 | 当てるもの |
|---|---|
| `人物` | 一人か数人の生涯を追う |
| `集団` | 国家・帝国・社会層など、続く人の集まり |
| `出来事` | 始まりと終わりのある事の運び |
| `概念史` | 主題を時代を跨いで追う |

`kind` とは別の軸である（ショート 老子・荘子 は種別が `人物` で `kind` は `concept`）。

### `tags` の主題（0 個でよい）

| | |
|---|---|
| 選び方 | 既に `series.json` に在る語を優先し、どれでも言えないときだけ新語を足す |
| 入れない | 地域名（`日本`・`ギリシア`）と、`eras.json` と同じ粒度の時代名（`先史`・`古代`・`中世`・`近世`・`近代`・`19世紀`・`20世紀`・`戦後`） |
| 入れてよい | era より細かい固有の時代名（`幕末`・`三国志`） |

### `id` の表記

| 対象 | 規則 | 例 |
|---|---|---|
| 漢字とかな | 日本語の読みをローマ字にする | `yoshida-shoin`・`shokatsu-komei` |
| カタカナの外来固有名 | 元の言語の表記を使う | `sparta`（`suparuta` でない）・`hitler`・`cleopatra` |
| ラテン文字で書かない言語の固有名 | カタカナの語形に合う綴りのうち、英語の文献で通用するものを使う。発音区別符号（`š`・`ā` など）を付けない | `alexandros`（`alexander` でない）・`cleopatra`（`kleopatra` でない）・`gilgamesh`（`gilgameš` でない） |
| 長音 | 記号でも母音の重ねでも表さない | `shukyo`（`shūkyō`・`shuukyou` でない）・`komei` |
| `・`・`＝`・序数 | `-` と算用数字へ置き換える | `roshi-soshi`・`levi-strauss`・`elizabeth-1` |
| 助詞 | 語として残す | `okane-no-rekishi`・`saicho-to-kukai` |
| 接頭辞 | `title` と同じく除く | |

### 事物の `id` の表記

事物（`loci.geojson`）の `id` は、シリーズの `title` でなく代表点の地名から作る。

| 対象 | 規則 | 例 |
|---|---|---|
| 地名 | 英語の文献で通用する表記を使う。日本語の読みにしない | `xianyang`（`kanyo` でない）・`carthage`・`rome`（シリーズ `teisei-roma` の `roma` と別の規則で決まる） |
| 発音区別符号・長音 | シリーズの `id` と同じく表さない | |
| 空白・`.` | 空白は `-` にし、`.` は除く | `st-louis` |
| 同じ地名を二つのシリーズが要求する | より具体的な地点名を使う | `sparta-city`・`forum-romanum` |
| 人名・シリーズ名 | 使わない | シリーズ `hannibal` の代表点は `carthage` |

## 理由

- **`region` を閉じた集合にする** — 等値で照合する鍵なので、`ギリシア` と `ギリシャ` の表記のゆれが「近くない」という正しく見える結果になる
- **区画を面積で揃えない** — 日本 14 件と中国 8 件を `東アジア` へ束ねると 22 件が同じ値になり、「`region` が同じ」が「同じ大陸」以上を言わなくなる。逆にヨーロッパの 12 件を国で割ると 1 件から 3 件の区画が並び、一致が滅多に起きなくなる
- **一覧を先に閉じる** — 値を足す判断は足す人ごとに違う。`朝鮮半島` の 1 件目を書くセッションが、`朝鮮半島` と `東アジア` と `中国` のどれを足すかを単独で決める状況を作らない
- **`tags` から地域名と era 級の時代名を除く** — その二つは `region` と `timeRange` が既に持つ。`古代` のタグは `timeRange` の粗い言い直しで、tag 絞り込みの一覧でスライダーがより正確にできることを重複して提示する
- **`幕末` と `三国志` は残す** — `eras.json` の区分は 7 つで、`幕末` の 4 件（吉田松陰・高杉晋作・ペリー来航・西郷隆盛）はどれも `19世紀` に入り、スライダーの上でゴッホやリンカンと同じ位置に並ぶ。`region: 日本` の 14 件も粗い。この 4 件だけを束ねる欄が他に無い
- **種別を必ず入れる** — 主題が 0 個のシリーズでも tag 絞り込みで選べる値を 1 つ残す
- **`title` から接頭辞を除く** — `title` はシリーズの主題を指す名の列で、`ショート 紫式部` を残すと列が主題の名だけを並べたものでなくなる。尺の情報は `episodes.json` の回のタイトルに残る
- **`place` と位置なしを組まない** — 土地が決まると宣言しながら点を置かないと、地図から消えたまま濃く描く指示だけが残る。`concept` と代表点の組は矛盾しないので許す
- **既存 10 件に例外を作らない** — 10 件を残す費用は S5 の #140（関連シリーズ行）まで消えず、そのときは 66 件の中から探すことになる
- **ラテン文字で書かない言語の名をカタカナの語形に合わせる** — `title` のカタカナが綴りの語形を決めるので、`title` だけを見て `id` を書ける。同じ語形の綴りが複数あるときだけ、英語の慣用で一つに決める
- **事物の `id` を地名の英語表記にする** — 座標の典拠（Pleiades・GeoNames）は地名をラテン文字で持つので、`id` をそのまま検索語にできる

### 採らなかった案

| 案 | 採らなかった理由 |
|---|---|
| `region` を自由記述のままにする | 等値の照合が表記のゆれで外れ、外れたことが関連シリーズ行の空白としてしか出ない |
| `region` を大陸の 6 値にする | アジアに 26 件が入り、一致が「同じ大陸」しか言わなくなる |
| `region` を国名で揃える | 古代の都市国家や帝国に当てる国名が無く、`スパルタ` を `ギリシア共和国` と書くことになる |
| `region` の一覧を開いたままにする | 値を足す判断が人ごとに違い、`朝鮮半島` と `東アジア` が両方できる |
| `北欧` を区画にする | ヨーロッパは 12 件で、割ると 1 件から 3 件の区画が並び一致が滅多に起きない |
| `ユーラシア` を残して通史へ当てる | 実在する区画の名でもあるので、位置を持つシリーズが使ったときに通史と混ざる。「教育の歴史」はアメリカも含むので嘘にもなる |
| 位置なしの `region` を空文字にする | `region` は非空の文字列なので、スキーマを緩めるか番兵の値を足す改修が要る。`地域なし` は同じことを既存のスキーマのまま言える |
| `tags` に地域名と era 級の時代名も残す | tag 絞り込み（#142）の一覧に `古代` と `日本` が並び、スライダーと地図が既にできることを二重に提示する |
| 時代名を粒度で分けず `幕末` も除く | 規則は一行で済むが、`幕末` の 4 件を束ねる欄がどこにも無くなる |
| 種別を専用の欄にする | 近接のためにスキーマを増やさないと `ARCHITECTURE.md` §4 が決めており、`tags` の中の閉じた集合で同じ絞り込みができる |
| 種別をちょうど 1 つに限る | 「サラディンと十字軍」のように人物と出来事の両方であるものを、どちらか一方だけに決めることになる |
| `ショート` を `tags` へ移す | 主題だけを持つと決めた `tags` へ番組の形式が入り、関連シリーズ行が「ショート 切腹」と「ショート ニコラ・テスラ」を近いものとして並べる |
| `id` をカタカナのローマ字化で揃える | 現物 10 件のうち 5 件が元の言語の表記で、揃えると `id` が変わる。`id` はエピソードと事物が指す先なので両方の参照も変わる |
| ラテン文字で書かない言語の名を英語の慣用形（`alexander`）で揃える | `title` のカタカナと `id` の語形が食い違い、`title` から `id` が決まらない。現物の `alexandros` も変わる |
| ラテン文字で書かない言語の名を学術転写（`kleopatra`）で揃える | 現物の `cleopatra` が変わり、それを指すエピソードと事物の参照も変わる |
| 事物の `id` もシリーズの `id` と同じく日本語の読みにする | 中国の事物 4 件（`xianyang`・`chengdu`・`luyi`・`pengcheng`）が変わり、座標の典拠を検索するたびに地名を英語表記へ戻すことになる |
| 既存 10 件を旧い語彙のまま残す | 66 件のうち 10 件だけが別の規則で書かれた状態が残り、関連シリーズ行を実装する S5 まで気付けない |

## 帰結

- #102 から #106 までの 5 つの issue は、この語彙に従って 50 件を書く。
  値の一覧と意味は issue 本文でなくこのレコードが持つ
- 主題の語は `series.json` の現物が正になる。
  書く前に現物の `tags` を読んで既存の語を再利用する
- `region` の一覧はコードの enum とこのレコードの二箇所に在る。
  値を足すときは両方が変わる
- `ROADMAP.md` の閾値 1 の判定は変わらない。
  公式一覧との突き合わせは `season` で行うので、`title` から接頭辞を除いても 66 件の数は変わらない
- `ARCHITECTURE.md` §3 のデータモデルの例も現物へ揃える

検査の範囲は次のとおり。

| `web/src/lib/schema/series.ts` が検査する | 検査で見られない |
|---|---|
| `region` が 13 値のどれか | 区画を一つ選ぶと嘘になるか |
| `tags` に種別が最低 1 つ在る | `id` の表記が読みどおりか |
| `tags` が 4 個以内 | 事物の `id` が地名の英語表記か |
| `tags` に era 級の時代名が無い | |
| `title` が接頭辞で始まらない | |
| `kind: place` と `ANCHOR_UNLOCATED` を組まない | |

左は 1 件の中で閉じるので `references.ts` でなくスキーマが見る。
右は外の知識が要るので、人間と `@historian`（[ADR-0035](0035-history-review-lane.md)）が見る。

## 覆る条件

関連シリーズ行（#140）を実装して、`region` の等値では近接を判定できないと分かったとき。
13 の区画のどれかに件数が偏り、`region` の一致が「同じ大陸」以上を言わなくなったとき。
この一覧に無い区画へ代表点を置く例が出たとき。
