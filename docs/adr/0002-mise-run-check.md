# 0002. 機械判定の口を `mise run check` 一本にする

- **状態**: supersede 済み（→ 0009）
- **決定日**: 2026-08-02
- **関係する ADR**: 0009（この決定を supersede する）

> このレコードは書き換えない。判定の口の現行は 0009。

## 文脈

作業単位の管理を GitHub Issues へ移行し、issue の完了条件を「機械判定」と「人間の判定」の
二本に分けた。機械判定の側が何を指すかを固定する必要がある。

## 決定

**`mise run check`** = Biome lint/format + `tsc --noEmit` + `vitest run`

## 理由

issue の完了条件を一つのコマンドへ集約する。判定の口が複数あると、どれが緑なら閉じてよいかが毎回議論になる（決定日 2026-08-02）。

## 帰結

- issue の完了条件は「`mise run check` が緑」と書けば足りる
- CI もこの一本を回す
- 口が一本であることが規約なので、増やすときはこの ADR を覆すことになる

## 覆る条件

タスクの置き場（mise tasks か `package.json` の scripts か）が、踏襲している
ツールチェーンの別の定めと衝突すると分かったとき。→ 実際に 2026-08-25 に衝突し、0009 が覆した。
