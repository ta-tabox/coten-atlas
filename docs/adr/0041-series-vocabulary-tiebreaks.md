- **状態**: 採用
- **決定日**: 2026-09-11（#171・#170・#172・#166・#164）
- **関係する ADR**: 0034（これを supersede する）、0008（引用は題号に限る）、0018（割当キーを `itunes:season` にする）、0023（`kind` は geometry から導けない差だけを持つ）、0026（位置情報の段階分け）、0027（シリーズと事物の分離）、0035（歴史の裏どりを `@historian` の別レーンに分ける）、0037（`catalog/` の値の典拠を `docs/sources/` に置く）、0039（時期なしの概念史のシリーズ）

## 文脈

0034 の語彙で、S7 の 4 つの PR（#165・#167・#168・#169）が 38 件を書いた。
0034 の規則が候補を一つに絞らない選択が 5 種類出て、PR ごとに別の基準で仮決定された。
パリでは、二つの PR が同じ事物の `id` `paris` を別々に作り、両方が main に入ると検査が赤になる状態になった。

| 選択 | 当たった現物の例 | issue |
|---|---|---|
| 人物・集団・出来事の拠点や舞台が複数ある | 織田信長の岐阜と安土・ガンディーのダーバンとアフマダーバード | #171 |
| 代表点の時代の地点が複数の名を持つ | 下関と赤間関・旅順と Port Arthur | #170 |
| `id` の語の区切りで、二つの辞書の見出しが割れる | 鎌倉武士（精選版日本国語大辞典にだけ一語の見出しがある） | #172 |
| 同じ地名を二つのシリーズが要求し、どちらが移るかが決まらない | パリ（フランス革命とレヴィ＝ストロース） | #166 |
| 仕えた国は伝わるが、その都が史料に都市名で書かれていない | 老子・荘子 | #164 |

このレコードは 0034 の決定をすべて複写し、5 種類の選び方を足す。
足す選び方のうち、中国の地名のピンインの条項と、人物の中心の場所に「仕えた国の都を含む」の二つは、0034 の文の意味を変える。

以下の 0034 の文脈は、語彙そのものを決めた時点のものである。

`series.json` の 66 件のうち 56 件を、#101 から #106 までの 6 つの issue が別々のセッションで書く。
`id`・`title`・`region`・`tags` は人手で書く欄なので、規則が無ければ 6 通りの語彙ができる。

`ARCHITECTURE.md` §4 は関連シリーズ行を「`tags` を共有するか `region` が同じ」で選ぶと決めている。
`region` は等値で照合する鍵なので、揃っていない値は「近くない」と同じ結果を返す。
関連シリーズ行が空になるだけで、壊れ方が画面に出ない。

先に書かれた 10 件が既に揃っていない。
`region` に `日本`・`ギリシア`・`ユーラシア`・`地中海〜西アジア` が同居し、`tags` は `["人物", "幕末", "日本"]` のように種別・時代・地域が同じ配列に入っている。

## 決定

### 欄ごとの規則

| 欄 | 規則 |
|---|---|
| `id` | シリーズ名の読みをローマ字にする（下の「`id` の表記」） |
| `title` | 先頭の番組内のコーナー名（`ショート`・`ジンブンガク`）を除く。除いた事実を `tags` にも持たせない |
| `kind` | 主題の中心の場所に代表点を置けば `place`、それ以外は `concept`（下の「代表点と `kind` の選び方」）。**`place` と `ANCHOR_UNLOCATED` は組まない** |
| `region` | 下の 13 値から 1 つ。そのシリーズが扱う地理の広がりを表す欄で、`anchor` とは独立に決まる |
| `tags` | 種別を最低 1 つ、主題を 0 個以上。合わせて 4 個以内 |

この語彙を既存の現物にも当てる。
旧い規則のまま残す例外を作らない。

### `region` の選び方

次の表を上の行から当て、最初に当てはまった行の値を書く。

| 順 | 状況 | 値 | 例 |
|---|---|---|---|
| 1 | 扱う地理が一区画に収まる | その区画 | 秦の始皇帝 → `中国`・ショート 切腹（位置なし） → `日本` |
| 2 | 複数の区画に跨るが、下の表の本拠が一つの区画に決まる | 本拠の区画 | アレクサンドロス → `ヨーロッパ`・ハンニバル → `アフリカ` |
| 3 | 複数の区画に跨り、下の表の本拠が無い | `地域なし` | 世界三大宗教 |

| `概念史` | 一つの区画で生まれて他へ広がったなら、生まれた区画 | 複数の区画で別々に生まれた | 世界三大宗教・お金の歴史 → `地域なし` |

| 継ぎ目 | 区画 |
|---|---|
| ロシア | ウラル山脈以西は `ヨーロッパ`、以東は `中央ユーラシア` |

| 値 | 当てるもの |

### `tags` の主題（0 個でよい）

| | |
|---|---|

### 代表点と `kind` の選び方

代表点と `kind` は、主題の中心の場所で決める。
中心の場所は、人物なら活動の拠点（治めた国や仕えた国の都を含む）、集団なら本拠の都市、出来事なら主な舞台である。
治めた国や仕えた国の都は、史料がその都を都市名で書くときに限って中心の場所に含める。
都を年代の推論でしか決められないときは、中心の場所が伝わらないとみなす（老子・荘子）。
種別が複数あるシリーズは、`region` の本拠と同じく `title` の中心になる語が当たる種別で決める。

拠点や舞台が複数あるときは、番組が扱う主な事績が起きた地を中心の場所とする。
出来事なら、番組が扱う主な事の運びが起きた舞台を中心の場所とする。
人物の治めた国の都と、本人が暮らして執務した地が別の都市なら、暮らして執務した地を先に見る。
選んだ地・他の候補・選んだ理由は、`docs/sources/<シリーズ id>.md` の「代表点」節に書く。

次の表を上の行から当て、最初に当てはまった行の値を書く。

| 順 | 状況 | `anchor` | `kind` | 例 |
|---|---|---|---|---|
| 1 | 種別が `概念史` だけ | `"unlocated"` | `concept` | 世界三大宗教・お金の歴史・ショート 切腹 |
| 2 | 出来事の舞台が複数の区画に対等に跨る | `"unlocated"` | `concept` | |
| 3 | 中心の場所が伝わっている | 中心の場所の事物の `id` | `place` | スパルタ → `sparta-city`・吉田松陰 → `hagi`・ハンニバル → `carthage` |
| 4 | 中心の場所が伝わらず、生地が伝わっている | 生地の事物の `id` | `concept` | 老子・荘子 → `ku`（老子の伝承上の生地） |
| 5 | 中心の場所も生地も伝わらない | `"unlocated"` | `concept` | |

| 対象 | 規則 | 例 |
|---|---|---|
| 漢字とかな | 日本語の読みをヘボン式でローマ字にする（`し`・`ち`・`つ`・`ふ`・`じ` は `shi`・`chi`・`tsu`・`fu`・`ji`） | `yoshida-shoin`・`shokatsu-komei` |
| 長音 | 記号でも母音の重ねでも表さない。`ou`・`oo` は `o`、`uu` は `u` にし、`ei`・`ii` はそのまま書く | `shukyo`（`shūkyō`・`shuukyou` でない）・`komei`・`teisei-roma` |
| 長音に続く同じ母音の字 | 長音と別の字として書く | `kou-to-ryuho`（`項羽` は `こう` と `う`） |
| `ん` | 後ろの音によらず `n` にする | `sandai`・`genpei`（`gempei` でない） |
| 語の区切り | 語と語の境目と、助詞の前後に `-` を入れる。辞書に一語で載る語と、接頭辞・接尾辞の付いた語は割らない。辞書に一語で載るかは、コトバンクで引けるデジタル大辞泉と精選版日本国語大辞典の見出しで判定し、どちらか一方に一語の見出しがあれば割らない | `sekai-sandai-shukyo`・`shin-no-shikotei`（`shi-kotei` でない）・`america-kaitakushi`（`kaitaku-shi` でない）・`okane-no-rekishi`・`kamakurabushi`（精選版日本国語大辞典にだけ「かまくら‐ぶし」の見出しがある） |
| 助詞 | 語として残す。`title` の表記に無くても、読みに在れば書く | `saicho-to-kukai`・`sugawara-no-michizane`（`菅原道真`） |
| カタカナの外来固有名 | カタカナの語形に合うラテン文字の綴りを使う。語形に合う綴りが複数あれば、英語の文献で通用するものを使う | `sparta`（`suparuta` でない）・`hitler`・`alexandros`（`alexander` はアレクサンダーの語形）・`cleopatra`（`kleopatra` でない）・`chinggis-khan`（`genghis-khan` はジンギスの語形） |
| 発音区別符号（`š`・`ü`・`é` など） | 付けず、元の字だけを書く | `gilgamesh`（`gilgameš` でない）・`levi-strauss`（`lévi-strauss` でない） |
| 大文字 | 小文字にする | `hitler`（`Hitler` でない） |
| `・`・`＝`・空白 | `-` に置き換える | `roshi-soshi`・`levi-strauss`・`julius-caesar` |
| `'`・`.` | 除く | `jeanne-darc`（ジャンヌ・ダルク） |
| 序数 | 算用数字にする | `elizabeth-1` |
| コーナー名 | `title` と同じく除く | |

### 事物の `id` の表記

事物（`loci.geojson`）の `id` は、シリーズの `title` でなく代表点の地名から作る。

| 対象 | 規則 | 例 |

#### 同じ地名を二つのシリーズが要求するとき

次の表を上の行から当て、最初に当てはまった行でどちらが移るかを決める。
種別は、代表点と `kind` の選び方と同じく、`title` の中心になる語が当たる種別で見る。
中心の場所は、拠点や舞台が複数あれば番組が扱う主な事績が起きた地である。

| 順 | 組 | 地名を使う側 | より具体的な地点名へ移る側 | 例 |
|---|---|---|---|---|
| 1 | 種別が `集団` か `出来事` のシリーズと、`人物` のシリーズ | `集団`・`出来事` | `人物` | `teisei-roma`（集団）が `rome`、`julius-caesar`（人物）が `forum-romanum` |
| 2 | 1 に当たらず、一方だけが中心の場所を都市の中の一か所（建物・邸宅・区画）に絞れる | 絞れない側 | 絞れる側 | `marx-engels`（ロンドンの中で住まいが移った）が `london`、`elizabeth-1`（ホワイトホール宮殿に絞れる）が `whitehall` |
| 3 | 1 にも 2 にも当たらない | `season` の小さい側 | `season` の大きい側 | `hitler`（8）が `berlin`、`goebbels`（39）が `wilhelmplatz` |

## 理由

- **`region` を閉じた集合にする** — 等値で照合する鍵なので、`ギリシア` と `ギリシャ` の表記のゆれが「近くない」という正しく見える結果になる
- **区画を面積で揃えない** — 日本 14 件と中国 8 件を `東アジア` へ束ねると 22 件が同じ値になり、「`region` が同じ」が「同じ大陸」以上を言わなくなる。逆にヨーロッパの 12 件を国で割ると 1 件から 3 件の区画が並び、一致が滅多に起きなくなる
- **一覧を先に閉じる** — 値を足す判断は足す人ごとに違う。`朝鮮半島` の 1 件目を書くセッションが、`朝鮮半島` と `東アジア` と `中国` のどれを足すかを単独で決める状況を作らない
- **`tags` から地域名と era 級の時代名を除く** — その二つは `region` と `timeRange` が既に持つ。`古代` のタグは `timeRange` の粗い言い直しで、tag 絞り込みの一覧でスライダーがより正確にできることを重複して提示する
- **`幕末` と `三国志` は残す** — `eras.json` の区分は 7 つで、`幕末` の 4 件（吉田松陰・高杉晋作・ペリー来航・西郷隆盛）はどれも `19世紀` に入り、スライダーの上でゴッホやリンカンと同じ位置に並ぶ。`region: 日本` の 14 件も粗い。この 4 件だけを束ねる欄が他に無い
- **種別を必ず入れる** — 主題が 0 個のシリーズでも tag 絞り込みで選べる値を 1 つ残す
- **`title` からコーナー名を除く** — `title` はシリーズの主題を指す名の列で、`ショート 紫式部` を残すと列が主題の名だけを並べたものでなくなる。尺の情報は `episodes.json` の回のタイトルに残る
- **`place` と位置なしを組まない** — 土地が決まると宣言しながら点を置かないと、地図から消えたまま濃く描く指示だけが残る。`concept` と代表点の組は矛盾しないので許す
- **既存 10 件に例外を作らない** — 10 件を残す費用は S5 の #140（関連シリーズ行）まで消えず、そのときは 66 件の中から探すことになる
- **カタカナの外来固有名をカタカナの語形に合う綴りにする** — `title` のカタカナが綴りの語形を決めるので、元の言語の文字によって規則を分けずに `sparta` から `chinggis-khan` までを 1 行で決められる。語形に合う綴りが複数あるときだけ、英語の慣用で一つに決める
- **ヘボン式・長音・`ん`・語の区切りの細則を決める** — 同じ読みから `shikotei` と `shi-kotei`、`genpei` と `gempei` の両方が作れる。`id` はエピソードと事物が指す先なので、後から揃え直すと参照も変わる
- **語の区切りを二つの辞書の見出しの和で判定する** — 辞書を名指さないと、引いた辞書によって同じ語が割れたり割れなかったりする。デジタル大辞泉は新しい語の見出し、精選版日本国語大辞典は古い複合語の見出しを持つので、和で引くと一語の語を割りにくい
- **事物の `id` を地名の英語表記にする** — 座標の典拠（Pleiades・GeoNames）は地名をラテン文字で持つので、`id` をそのまま検索語にできる
- **事物の `id` を代表点に選んだ時代の地名にする** — 代表点を選ぶときに読むのはシリーズの内容で、そこに出る名は当時の名（彭城・苦県）である。現在の名にすると、書く側が当時の名から現在の名への対応を調べることになり、調べた先によって `id` が割れる
- **その時代の地点が複数の名を持つときは、現在の英語の文献の慣用で決める** — その時代の公称は、租借地や占領地のように治める政権が二重になる地点（旅順・クラクフ）と、公称が伝わらない地点（アウラガ）で一つに決まらない。英語の文献の慣用なら `@historian` が文献で確かめられる
- **慣用を、その時代でなく現在の英語の文献で見る** — 洛陽（7 世紀）やアウラガ（13 世紀）には、その時代に書かれた英語の文献が無い。当時の呼び名を改称の時期から決めると、アンカラ（Ankara への改称を 1923 年とする説と、対外的な切り替えを 1930 年とする説）のように、改称の時期で典拠が割れる
- **中国の地名にも英語の文献の慣用を先に当てる** — 地点の名を英語の文献の慣用で決めるので、中国の地名だけを例外にすると規則が二本になる。`xianyang`・`chengdu`・`pengcheng`・`ku` は英語の文献もピンインで書くので変わらない
- **シリーズの `id` と同じ文字列を事物の `id` にしない** — `anchor` の値だけを見て、それがシリーズの `id` か事物の `id` かを取り違えない
- **同じ地名は、まず種別で分ける** — `集団` の代表点は本拠の都市、`出来事` の代表点は主な舞台で、どちらも都市そのものを指すことが多い。0034 の例（`teisei-roma` が `rome`、`julius-caesar` が `forum-romanum`）も、この分け方で説明できる
- **同じ種別どうしは、一か所に絞れる側が移る** — 絞れる側は移っても事績の地を指したままである。絞れない側を建物へ移すと、事績の一部だけが舞台に見える
- **最後は `season` で決める** — `season` は 1 シリーズに 1 つで重ならないので、書く順や PR の並びによらず必ず決まる
- **主題の語の形と下位語の扱いを決める** — 主題は等値で照合するので、`戦争` と `戦争史`、`戦争` と `内戦` が並ぶと、同じ主題のシリーズが関連シリーズ行で一致しなくなる
- **4 個を超えたときに削る順を件数で決める** — 件数の少ない語は他のシリーズと一致しにくいので、削っても関連シリーズ行から消える組が最も少ない。書き手の好みで削る語が変わらない
- **別の区画と同じ名の時代名を入れない** — `戦国` を中国と日本のシリーズが共有すると、関連シリーズ行が時代も地域も違うシリーズを近いものとして並べる
- **本拠を種別ごとに一つの基準で決める** — 出自・活動の中心・帰る場所を並べるだけでは、ハンニバル（生地はカルタゴ、活動の中心はイタリア）のように基準ごとに区画が変わる。現物のアレクサンドロス・ハンニバル・クレオパトラ・帝政ローマは、どれも生地か発祥の地で決まっている
- **種別が複数あるシリーズは `title` の中心になる語で決める** — `tags` の種別の並びに順序の意味は無く、主題を名指しているのは `title` である
- **代表点と `kind` を主題の中心の場所で決める** — 「主題そのものが土地に在るか」だけでは、`思想` を主題に持つ吉田松陰（`place`）と老子・荘子（`concept`）の違いを言えない。違いは、代表点が活動の拠点か、拠点が伝わらず生地に置いたかにある
- **拠点や舞台が複数あるときは事績の中心で選ぶ** — 地図が答える問いは「どの場所の話か」なので、代表点を番組が扱う事績の地に合わせる。どこを中心と見るかは書き手の判断に残るので、候補と理由を典拠のファイルに残し、レビューと `@historian` が同じ基準で覆せるようにする
- **出来事にも同じ基準を当てる** — 出来事の舞台を各回の配分で選ぶ規則を別に立てても、事績の中心とほぼ同じ地を指し、規則が二本になるだけである
- **人物は暮らして執務した地を治めた国の都より先に見る** — 事績は本人が居た地で起きる。フリードリヒ大王は王の居所のポツダムで、首都のベルリンではない
- **仕えた国の都は、史料が都市名で書くときだけ中心の場所に含める** — 『史記』は老子の仕え先を「周」とだけ書き、周の都は老子の伝承上の年代と都の移り変わりを重ねる推論でしか決まらない。推論で都を選ぶと、年代の説を一つ選び直すたびに代表点が動く
- **種別が `概念史` だけのシリーズを位置なしにする** — 現物の概念史 2 件はどちらも位置なしで、主題が時代を跨いで各地に広がるので 1 点を置くとその場所だけが舞台に見える

### 採らなかった案

| 案 | 採らなかった理由 |
|---|---|
| `region` を自由記述のままにする | 等値の照合が表記のゆれで外れ、外れたことが関連シリーズ行の空白としてしか出ない |
| `region` を大陸の 6 値にする | アジアに 26 件が入り、一致が「同じ大陸」しか言わなくなる |
| `region` を国名で揃える | 古代の都市国家や帝国に当てる国名が無く、`スパルタ` を `ギリシア共和国` と書くことになる |
| `region` の一覧を開いたままにする | 値を足す判断が人ごとに違い、`朝鮮半島` と `東アジア` が両方できる |
| `北欧` を区画にする | ヨーロッパは 12 件で、割ると 1 件から 3 件の区画が並び一致が滅多に起きない |
| `ユーラシア` を残して通史へ当てる | 実在する区画の名でもあるので、位置を持つシリーズが使ったときに通史と混ざる。「教育の歴史」はアメリカも含むので嘘にもなる |
| 位置なしの `region` を空文字にする | `region` は非空の文字列なので、スキーマを緩めるか番兵の値を足す改修が要る。`地域なし` は同じことを既存のスキーマのまま言える |
| `tags` に地域名と era 級の時代名も残す | tag 絞り込み（#142）の一覧に `古代` と `日本` が並び、スライダーと地図が既にできることを二重に提示する |
| 時代名を粒度で分けず `幕末` も除く | 規則は一行で済むが、`幕末` の 4 件を束ねる欄がどこにも無くなる |
| 主題に複合語を許す | `宗教思想` と `宗教` が別の値になり、等値の照合が外れる |
| 人物の本拠を活動の中心にする | 現物のアレクサンドロス（活動の中心は西アジア）とハンニバル（イタリア）の `region` が変わり、活動の中心をどこと見るかで書き手ごとに割れる |
| 種別が複数あれば `tags` に先に書いた種別で本拠を決める | `tags` の並び順が `region` を変えることになり、並べ替えただけの差分が近接を変える |
| `kind` を主題が思想かどうかで分ける | `思想` を主題に持つ吉田松陰が `concept` になり、現物と食い違う |
| 実在が定説でない人物を `concept` にする | 実在が議論されるギルガメシュも、拠点のウルクに代表点を置いた `place` である。実在の定説をどこまで調べるかでも書き手ごとに割れる |
| 拠点が複数あるとき、最後の拠点を選ぶ | 一意に決まりやすいが、晩年の住まいや番組が主に扱わない時期の地に点が立つ |
| 拠点が複数あるとき、最も長い拠点を選ぶ | 期間の数え方で書き手ごとに割れる。ガンディーのダーバンのように、`region` と別の区画に点が立つこともある |
| 拠点が複数あるときの選び方を規則にしない | 件ごとに人間の判定が要る。S7 の仮決定では、基準が最後の拠点・最初の都・最も長い拠点など件ごとに割れた |
| 人物の治めた国の都を、暮らして執務した地より先に見る | 本人が居なかった都に点が立つ。フリードリヒ大王をベルリンに置くと、ヒトラーとベルリンを取り合う |
| 仕えた国が伝わり、その時代の都が年代から一つに定まれば、都を中心の場所とみなす | 老子・荘子の代表点が、史料に無い都市名（王城）に年代の推論で決まる |
| `戦国` を地域名と組み合わせて `日本戦国` のように書く | 地域名を `tags` に入れない規則と重なり、`region` が既に持つことを二度書く |
| 種別を専用の欄にする | 近接のためにスキーマを増やさないと `ARCHITECTURE.md` §4 が決めており、`tags` の中の閉じた集合で同じ絞り込みができる |
| 種別をちょうど 1 つに限る | 「サラディンと十字軍」のように人物と出来事の両方であるものを、どちらか一方だけに決めることになる |
| `ショート` を `tags` へ移す | 主題だけを持つと決めた `tags` へ番組の形式が入り、関連シリーズ行が「ショート 切腹」と「ショート ニコラ・テスラ」を近いものとして並べる |
| `id` をカタカナのローマ字化で揃える | 現物 10 件のうち 5 件が元の言語の表記で、揃えると `id` が変わる。`id` はエピソードと事物が指す先なので両方の参照も変わる |
| カタカナの外来固有名を英語の慣用形（`alexander`・`genghis-khan`）で揃える | `title` のカタカナと `id` の語形が食い違い、`title` から `id` が決まらない。現物の `alexandros` も変わる |
| カタカナの外来固有名を元の言語の学術転写（`kleopatra`・`iulius-caesar`）で揃える | 現物の `cleopatra` と `julius-caesar` が変わり、それを指すエピソードと事物の参照も変わる |
| 元の言語がラテン文字で書くかどうかで規則の行を分ける | `cleopatra` のようにどちらの行でも同じ綴りになる名が出て、読み手はどちらの行を当てたかを決められない |
| 語の区切りを辞書一つの見出しで判定する | 固定しなかった辞書にだけ一語で載る語が割れる。デジタル大辞泉だけにすると、`kamakurabushi` が `kamakura-bushi` になる |
| 二つの辞書の両方に一語の見出しがあるときだけ割らない | 一方の辞書にだけ一語で載る語が割れ、`kamakurabushi` が `kamakura-bushi` になる |
| 漢字とかなを訓令式（`sikotei`）で書く | 現物の `shin-no-shikotei`・`yoshida-shoin`・`sekai-sandai-shukyo` が変わる |
| 事物の `id` もシリーズの `id` と同じく日本語の読みにする | 中国の事物 4 件（`xianyang`・`chengdu`・`ku`・`pengcheng`）が変わり、座標の典拠を検索するたびに地名を英語表記へ戻すことになる |
| 事物の `id` を現在の地名にする | 現物の `pengcheng`（徐州）と `uruk`（ワルカ）が変わり、書く側が当時の名から現在の名への対応を毎回調べることになる |
| その時代の地点が複数の名を持つとき、その時代の公称を使う | 治める政権が二重になる地点と公称が伝わらない地点で、値が一つに決まらない。下関は、英語の文献が使わない `akamagaseki` になる |
| 地点の名の慣用を、その時代に書かれた英語の文献で見る | 英語の文献が書かれる前の時代の地点に、規則が当たらない |
| 中国の地名を、英語の文献の慣用によらずピンインで書く | 地点の名の選び方が中国の地名だけ別になる。旅順が、英語の文献が日露戦争について使わない `lushun` になる |
| 同じ地名を二つのシリーズが要求したとき、`series.json` へ先に載った側が地名を使う | 並行して開いた PR どうしで順が決まらない |
| 同じ地名を二つのシリーズが要求したとき、両方がより具体的な地点名へ移る | 帝政ローマのように本拠が都市そのものである集団に、建物の点を付けることになる |
| 同じ地名を二つのシリーズが要求したとき、種別を見ずに一か所に絞れるかだけで決める | 両方とも絞れる組と両方とも絞れない組の決め方が無い。集団や出来事と人物の組でも、書き手の判断が要る |
| 既存 10 件を旧い語彙のまま残す | 66 件のうち 10 件だけが別の規則で書かれた状態が残り、関連シリーズ行を実装する S5 まで気付けない |

## 帰結

- S7 の 4 つの PR（#165・#167・#168・#169）は、main を取り込んでこの語彙で値を当て直す
- ADR は決定の理由と経緯を持つ記録で、値を書くたびに読む文書ではないので、値の一覧と意味の正本は skill `series-vocabulary` が持つ。
  このレコードは、決めた理由と採らなかった案を持つ。
  規則を変えるときは、同じ PR で skill の表を直し、理由を新しい ADR に書く
- 主題の語は `series.json` の現物が正になる。
  書く前に現物の `tags` を読んで既存の語を再利用する
- `region` の一覧はコードの enum と skill `series-vocabulary` の二箇所に在る。
  値を足すときは両方が変わり、足す理由を新しい ADR に書く
- `ROADMAP.md` の閾値 1 の判定は変わらない。
  公式一覧との突き合わせは `season` で行うので、`title` からコーナー名を除いても 66 件の数は変わらない
- 0034 の帰結のうち、`ARCHITECTURE.md` §3 の例を現物へ揃えることと、`roshi-soshi` の代表点を `luyi` から `ku` へ改名することは、0034 の時点で済んでいる
- 拠点や舞台が複数あるときの事績の中心は、番組の各回が何を主に扱うかで決まるので、`@historian`（ADR-0035）の裏どりでは決まらない。
  `@historian` は候補の地点の事実を確かめ、どれを事績の中心とするかは人間が PR で決める

検査の範囲は次のとおり。

| `web/src/lib/schema/series.ts` が検査する | 検査で見られない |
|---|---|
| `region` が 13 値のどれか | 区画を一つ選ぶと嘘になるか・本拠をどの種別の基準で決めたか |
| `tags` に種別が最低 1 つ在る | `id` の表記が読みどおりか |
| `tags` が 4 個以内 | 事物の `id` が代表点の時代の地名を英語で書いたものか |
| `tags` に era 級の時代名が無い | `tags` に地域名・コーナー名・別の区画と同じ名の時代名が無いか |
| `title` がコーナー名で始まらない | 主題の語が既存の語と同じ意味の新語や複合語でないか |
| `kind: place` と `ANCHOR_UNLOCATED` を組まない | `anchor` と `kind` が主題の中心の場所で決まっているか |

左は 1 件の中で閉じるので `references.ts` でなくスキーマが見る。
右は外の知識が要るので、人間と `@historian`（[ADR-0035](0035-history-review-lane.md)）が見る。
