# 0039. 時代を跨いで続く概念史のシリーズは、`timeRange` に年を書かず時期なしの印を置く

- **状態**: 採用
- **決定日**: 2026-09-10（#159）
- **関係する ADR**: 0019（終わっていない era の `end` は年を書かず、印を置く）、0026（位置情報の段階分け）、0027（シリーズと事物の分離）、0034（手で書く欄の語彙）

## 文脈

`series.json` の `timeRange` は、全シリーズで必須の年の閉区間である。
S7 で通史・概念史のシリーズ（#106）を書くと、史実の年で書けない端が二種類出た。

| 端 | 書いた値 | 値が指すもの |
|---|---|---|
| 先史まで遡る主題の `start` | -10000 | era 空間の始端。番組が扱う年代ではない |
| 現在まで続く主題の `end` | 最終回の配信年 | 番組を配信した年。主題の終わりではない |

後者は、0019 が era について退けた「終わっていない区間に年を書く」形である。
`okane-no-rekishi`（お金の歴史）の `end` 2020 も同じ形をしている。

位置なしのシリーズは地図に出ないので、`timeRange` を読む表示の大半に現れない。
opacity と同時代ハイライトは地図の上の表示で、一覧パネルの別区画を現在窓で絞るかは未決である（`ARCHITECTURE.md` §8）。

## 決定

**種別が `概念史` だけで位置なしのシリーズは、主題が終わっていて両端を史実の年で言えるときだけ `timeRange` に年を書き、それ以外は時期なしの印 `"untimed"` を置く。**

| シリーズ | `timeRange` | 例 |
|---|---|---|
| 種別が `概念史` だけで位置なし、主題が終わっていて両端を史実の年で言える | 年の閉区間 | ショート 切腹 |
| 種別が `概念史` だけで位置なし、上の行に当たらない | `"untimed"` | お金の歴史・世界三大宗教 |
| 上の二行に当たらない | 年の閉区間。`"untimed"` を置けない | スパルタ・老子・荘子 |

端の片方でも取り決めの値（era 空間の始端・配信年）でしか書けないなら、「両端を史実の年で言える」に当たらない。
世界三大宗教の年の範囲は開祖の時代を指すが、主題の宗教が続いているので `"untimed"` にする。

| 箇所 | `"untimed"` の扱い |
|---|---|
| `web/src/lib/schema/series.ts` | 受ける。置いたシリーズの種別が `概念史` だけで、`anchor` が `"unlocated"` であることを検査する。定数名は `TIME_RANGE_UNTIMED` |
| `web/src/lib/schema/references.ts` | era 空間との重なりと、事物の年の収まりを見ない |
| 事物の `timeRange: "series"` | `"untimed"` のシリーズは位置なしで事物を持たないので、解決する経路が無い。解決を求められたら throw する |

この決定は、概念史以外で現在まで続く主題の `end` をどう書くかを決めない。
時期なしのシリーズを一覧パネルと詳細カードでどう見せるかも決めない。

## 理由

- **年を書かない** — 取り決めの値は史実の年と見分けが付かず、era 空間の始端や配信年が主題の年代として読まれる。0019 と同じく、どの値を書いても嘘になる
- **印を置けるシリーズを概念史だけの位置なしに限る** — 事物・opacity・同時代ハイライトが印を受け取る経路が生まれず、印の分岐がスキーマと参照の検査の中に閉じる
- **期間が意味を持つシリーズには年を残す** — 切腹の 988..1868 は、主題がいつの話かを年で言える
- **線を「主題が終わっていて両端を史実の年で言える」にする** — 番組の構成でなく主題の性質で決まるので、書き手ごとに割れにくい
- **`null` にしない** — `null` は値が無い理由を語らない（0019 と同じ）

採らなかった案:

| 案 | 採らなかった理由 |
|---|---|
| 位置なしのシリーズを一律に時期なしにする | 位置なしは 0034 の「代表点と `kind` の選び方」の表の 2 行目と 5 行目でも生じ、そこに当たるシリーズは時期がはっきりしている |
| 種別が `概念史` だけのシリーズを一律に時期なしにする | 切腹のように期間が意味を持つシリーズの年代を捨てる |
| `end` に 0019 の `"present"` を許す | 現在まで続く主題の `end` は書けるが、先史まで遡る主題の `start` が取り決めの値のまま残る |
| `end` を最終回の配信年にする | 番組の配信年で、主題の終わりではない |
| `timeRange` を省略できる欄にする | 欄が欠けた理由を語らない。`null` と同じ |

## 帰結

- `series.json` の `okane-no-rekishi` と `sekai-sandai-shukyo` の `timeRange` を `"untimed"` にする
- 年の閉区間の型 `SeriesTimeRange` は変えず、シリーズの `timeRange` の型が `SeriesTimeRange | "untimed"` になる。
  opacity を求める関数は、地図に出るシリーズだけを受け取るので `SeriesTimeRange` のまま受ける
- `web/src/lib/map/loci.ts` が throw する経路は、`references.ts` の `brokenAnchors` が位置なしのシリーズの事物を名指すので、ビルドまで残らない
- S7 の各 issue は、種別が `概念史` だけで位置なしのシリーズの `timeRange` をこの線で書く。
  skill `series-vocabulary` は、この線を `tags` と代表点の後に当てる手順として持つ
- `ARCHITECTURE.md` §8 に、時期なしのシリーズの見せ方と、概念史以外で現在まで続く主題の `end` の書き方を開いた問いとして残す

## 覆る条件

時期なしのシリーズを era スライダーや同時代ハイライトの対象にする見せ方を決めたとき。
概念史以外に、両端を史実の年で言えないシリーズが出たとき。
