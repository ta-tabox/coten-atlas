# スモークを、デスクトップの Chromium に加えて、スマホの幅の WebKit と Chromium でも回す（20260828-e2e-offline-smoke を supersede）

- **状態**: 採用
- **決定日**: 2026-11-12
- **関係する ADR**: 20260828-e2e-offline-smoke（これを supersede する）、20260829-playwright-runner（スモークを Playwright で回す）、20260914-pnpm-check-current-form（判定のエントリポイントは `pnpm check` の一本）

## 文脈

20260828-e2e-offline-smoke は、E2E を外部を遮断したスモーク 1 枚に限り、ブラウザを Chromium 1 つに限ると決めた。
守らせるのは静的成果物が自足していることの一点だけで、地図の絵が正しいかは人間の目視に残した。

公開画面はスマホの幅で開かれる。
スマホの幅（iPhone 13 の 390px）では、一覧パネルが初期で画面の約 3/4 を覆い、詳細カードが一覧パネルの上に重なり、MapLibre の出典表記が era スライダーの年のラベルに重なる。
どれも 4xx も `console.error` も出さないので、スモークは緑のまま通る。
スモークの viewport は幅 1280・高さ 800 だけで、スマホの幅を開く検査は無い。

人間は、スマホの対象を iPhone と Android の両方とし、それぞれをその端末のブラウザと同じエンジンで機械に見させると決めた。

## 決定

スモークを三つの端末の条件で回す。

| 条件         | ブラウザ | viewport の出どころ                               |
| ------------ | -------- | ------------------------------------------------- |
| デスクトップ | Chromium | 固定の寸法（決定時点は 1280×800）                 |
| iPhone       | WebKit   | Playwright の `devices`（決定時点は `iPhone 13`） |
| Android      | Chromium | Playwright の `devices`（決定時点は `Pixel 7`）   |

外部（タイル・グリフ・スプライト）への通信の遮断と、スタイルだけを合成のフィクスチャで返すことは変えない。

三つの条件のどれでも、静的成果物が自足していること（同一オリジンへの 4xx / 5xx が無い・`console.error` が出ない・地図の canvas が viewport 大で立つ）を見る。

スマホの二つの条件では、加えて画面の配置の崩れを見る。
見るのは、部品の要素の矩形が互いに重ならないことと、画面の外へ出ないことのように、DOM の矩形から機械が判定できる条件に限る。

エントリポイントは `pnpm check` の中の `pnpm smoke` のままにし、別のエントリポイントを作らない。

**地図の絵が正しいかと、iOS の Safari のタッチの手触りは見ない。**
それは人間の目視と実機の確認に残す。

端末の条件ごとの寸法と、各条件で見る項目の現況は `web/playwright.config.ts` と `web/tests/smoke/` が持つ。

## 理由

- iPhone の Safari と Android の Chrome は描画エンジンが違うので、CSS の解釈の差（`dvh`・`-webkit-` 接頭辞の擬似要素・`overscroll-behavior`）による崩れは、その端末と同じエンジンでなければ捕まらない
- Playwright の WebKit は Linux のヘッドレスで地図を描ける（決定日に `devices["iPhone 13"]` で開き、canvas が 390×664 で立ち、`console.error` が出なかった）
- 部品の重なりは 4xx も `console.error` も出さないので、自足の三点だけでは捕まらない
- Playwright の WebKit は iOS の WebKit の `<input type="range">` のタッチの処理を通らず、スワイプを送る API も持たない（#241（iPhone の Safari で era スライダーのスワイプが効かない不具合）で確かめた）ので、タッチの手触りは実機に残す

以下は 20260828-e2e-offline-smoke の理由から変わらない部分の複写である。

- ヘッドレスのブラウザは地図を描ける
  Playwright の Chromium は WebGL を SwiftShader（ソフトウェアラスタライザ）で通し、`visibilityState` は `visible` になるので、`requestAnimationFrame` が回ってラベルまで描画される
- 外部を遮断しても配信物の自足の穴は捕まる
  maplibre はスタイルにソースが無くても worker を要求するため、404 の側が残る
  事故を捕まえるのは 4xx であって画素ではない
- canvas の寸法は配信物の自足の穴を捕まえないが、CSS で高さが 0 になる別の失敗に効く

| 採らなかった案                                              | 採らなかった理由                                                                                                 |
| ----------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| Chromium だけで iPhone と Android の寸法を開く              | 入れるブラウザは増えないが、Safari に固有の CSS の崩れを捕まえられない                                           |
| WebKit で iPhone の条件だけを足す                           | Android の Chrome の寸法と既定の描画を見る条件が無くなる                                                         |
| スマホの幅の検査を足さず、実機の目視だけで見る              | 配置の崩れを PR ごとに機械が止められず、回し忘れが起きる                                                         |
| スマホの検査を別のエントリポイント（`pnpm e2e` など）にする | 「これが緑なら閉じてよい」と言えるエントリポイントが二本になる                                                   |
| 実タイルまで叩いて画素を見る                                | `docs/HARNESS.md`「実 API を自動テストで叩かない」を書き換えることになり、外部の可用性で CI が赤くなる余地が入る |
| タイルをフィクスチャで再現して画素を見る                    | フィクスチャが数 MB になり、maplibre の版と一緒に古くなる                                                        |

## 帰結

- CI と、リモートのコンテナの準備のスクリプトは、Chromium に加えて WebKit とその OS の依存を入れる
- `pnpm smoke` の実行時間は、端末の条件の数に応じて伸びる
- 公開画面の配置を変える PR は、スマホの二つの条件で部品の矩形が重ならないことを保つ
- スモークが緑でも、地図が正しく描かれていることと、iPhone の実機でタッチが効くことの保証にはならない
- 配信は `BASE_PATH` 込みで行う（20260828-e2e-offline-smoke から変わらない）

## 覆る条件

- Playwright が iOS のタッチの経路（iOS Simulator の Safari など）をヘッドレスで回せるようになったとき（iPhone の条件を、そちらへ替えるかを選び直す）
- WebKit の条件が、ヘッドレスの WebGL の不安定さで偽陽性の赤を出し始めたとき（iPhone の条件を Chromium の寸法へ戻すか、canvas の寸法を判定から外すかを選び直す）
- `pnpm smoke` の実行時間が、手元で区切りごとに回せない長さになったとき（スマホの条件を CI だけで回すかを選び直す）
- タイル URL やスタイルの取り違えが実際に事故として出たとき（実タイルを叩くか、タイルのフィクスチャを持つかを選び直す。20260828-e2e-offline-smoke から変わらない）
- 公開画面のスマホの対象から、iPhone か Android のどちらかを外すとき
