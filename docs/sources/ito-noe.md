## 代表点

| 欄 | 値 |
|---|---|
| 典拠が示す値 | 139.767125, 35.681236（東京駅。東京の一般の点として） |
| 典拠 | [Wikipedia: 東京駅](https://ja.wikipedia.org/wiki/%E6%9D%B1%E4%BA%AC%E9%A7%85) |
| 典拠の格 | 参考程度 |

`@historian` は、現在の値が東京駅の座標とほぼ一致すると確認した。
住まいが東京の中で何度も移って一つの拠点に絞れないので、東京駅を東京の一般の点として置く扱いは `paris` と同じ水準にあり、問題は無いと判断した。

代表点を東京に置いたのは、第 2・3・5 回が扱う青鞜社での活動の地で、没地でもあるためである。

| 候補 | 置くと何が起きるか |
|---|---|
| 東京（現在値） | 青鞜社での活動の地に点が立つ |
| 今宿（生地。現在の福岡市西区） | 活動の拠点でない点が立つ |

東京は `yanase-takashi`（やなせたかし）も要求している。
やなせたかしの仕事場は新宿区片町に定まるので、[ADR-0034](../adr/0034-series-vocabulary.md) の事物の `id` の表の「同じ地名を二つのシリーズが要求する」行で、やなせたかしの側をより具体的な地点名 `shinjuku` にした。

事物の `id` の `tokyo` は、`@historian` が、対象の期間（1895〜1923 年）には東京の名が定着しており呼び名の変わりが無いと確認した。

## `region`・`kind`・`title`

`region: 日本` は、扱う地理が一区画に収まるので ADR-0034 の `region` の選び方の表の 1 行目で決めた。
`@historian` は、生地と没地がどちらも日本に在ることを確認した。

`title: 伊藤野枝` は、シリーズ名の「ショート 伊藤野枝」からコーナー名を除いたものである。
`id` の `ito-noe` は、現物の `yoshida-shoin` に揃えて姓と名を別の語として割った。
`kind: place` と `title` に指摘は出なかった。
