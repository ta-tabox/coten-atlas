# 典拠 — `catalog/` の値を決めた根拠

`catalog/series.json` の `timeRange` と `catalog/loci.geojson` の座標は、番組の内容から人手で決める値である。
`pnpm check` が見るのはスキーマと参照の整合だけなので、生没年が 50 年ずれていても座標が別の大陸を指していても検査は緑になる。
どの典拠に当たってその値にしたかを、シリーズごとにこのディレクトリへ残す。

置くと決めた理由は [ADR-0037](../adr/0037-sources-layer.md) が持つ。

## 「典拠」と「出典」を呼び分ける

このリポジトリの「出典」は、番組の題号と配信リンクを引用したときの帰属を指す（[ADR-0008](../adr/0008-quote-titles-only.md)。表記の全文は `/about`）。
史実の裏づけは帰属と別の事柄なので、「典拠」と呼ぶ。

## 置き方

- **1 シリーズ 1 ファイル。** ファイル名は `<シリーズ id>.md` で、`catalog/series.json` の `id` と一致させる。連番を鍵にしない
- **ファイルが在ることが、そのシリーズの裏どりが済んだ印である。** 争点があるものだけ作ると、「争点なし」と「未調査」が同じ外形になる。争点が無ければ「無し」と書く
- **値は常に決着している。** 学説が並立していても `catalog/` の値は 1 つに決め、他の説は「仮決定と論点」節が覆りうる根拠として持つ
- **ファイルが無いシリーズは未調査である。** 66 件すべてが揃うまで、無いことは「争点なし」を意味しない
- **公開サイトへ出さない。** 読む相手は、このリポジトリを開いて `catalog/` の値を疑う人に限る

## ファイルの型

各ファイルは次の並びで書く。
値の正は `catalog/` の側にあり、各ファイルは根拠だけを持つ。

| 節 | 何を持つか |
|---|---|
| 見出しの下の表 | `catalog/series.json` と `catalog/loci.geojson` のどの鍵と値に対応するか |
| `timeRange` | 欄ごとの値・何の年か・典拠・並立する説 |
| 代表点 | 典拠が示す座標・典拠・典拠の格。代表点を選んだ判断と候補 |
| `region`・`kind`・`title` | 裏どりが見た結果 |
| 仮決定と論点 | 人間が決着させた値と、覆りうる根拠 |
| 裏どりの出所 | 典拠を返した裏どりの回と、判断が出た PR。同じ欄を二度裏どりしたときは、どの回の典拠が正かを書く |

## 典拠の格

座標の典拠には格を添える。
区分は、`@historian` の報告の書式（`.github/historian-prompt.md`）が使う一次・二次・三次・参考程度の 4 つに、典拠に使わないものを足した 5 つである。

| 格 | 何を指すか | 値の確からしさを何が担保するか | 例 |
|---|---|---|---|
| 一次 | 対象と同時代に書かれた史料 | 当事者か同時代の記録者が書いたこと。書き手の立場による偏りは残る | カエサル『ガリア戦記』 |
| 二次 | 一次史料や発掘報告を読んで書かれた研究と、専門家が編集する学術的な地名辞典 | 著者と編集者の専門性と、一次史料への参照 | Pleiades |
| 三次 | 研究をまとめた事典・百科と、編集は誰でも行えるが地名辞典の値を取り込んだデータベース | 編集の責任者が辿れること | Britannica・World History Encyclopedia・Wikidata の `P625` |
| 参考程度 | 一次から三次のどれにも当たらない情報源 | 無し。値を決める根拠にせず、並立する説の在り処を示すのに留める | GlobalSecurity.org |
| 典拠に使わない | 内容を自動生成・転載した集約サイト | 無し | `latitude.to`・`geodatos.net` |
