## 代表点

| 欄 | 値 |
|---|---|
| 典拠が示す値 | 新宿区片町（やなせスタジオの所在地。曙橋駅の近く） |
| 典拠 | [新宿区ゆかりの人物データベース: やなせたかし](https://www.library.shinjuku.tokyo.jp/database/jinbutuyukari/080/post250.html)（三次）、[Yahoo!マップ: やなせスタジオ](https://map.yahoo.co.jp/v3/place/by7uSA2DVW6)（参考程度） |
| 典拠の格 | 所在地は三次、座標は参考程度 |

`@historian` は、やなせスタジオの所在地が新宿区片町であることを確認した。
現在の値は、最寄りの曙橋駅（139.72278, 35.692389）から約 300m 以内に在り、片町を指す点として妥当と判断した。

代表点を東京の新宿に置いたのは、やなせたかしが仕事場のやなせスタジオを新宿区片町に長く置いたためである。

活動の拠点の都市は東京だが、`tokyo` を `ito-noe`（伊藤野枝）も要求している。
同じ地名を二つのシリーズが要求したときの決め方（#166、[ADR-0041](../adr/0041-series-vocabulary-tiebreaks.md)）を上の順から当てると、次のとおりになる。

| 順 | 当てた結果 |
|---|---|
| 1 | 二つとも種別が `人物` なので当たらない |
| 2 | やなせたかしの中心の場所は仕事場のやなせスタジオ（新宿区片町）に絞れ、伊藤野枝の住まいは東京の中で何度も移って一か所に絞れない。絞れるやなせたかしが、より具体的な地点名 `shinjuku` を使う |

| 候補 | 置くと何が起きるか |
|---|---|
| 新宿（現在値） | 仕事場の在った区に点が立つ |
| 東京 | `ito-noe` の `tokyo` と同じ地名になり、#166 の順 2 でやなせたかしが移る側に当たる |
| 高知（育った地） | 活動の拠点でない点が立つ |

事物の `id` の `shinjuku` は、行政区分の語の「区」を付けなかった。
`@historian` は、綴りと呼び名に時代による変わりが無いと確認した。

## `region`・`title`

`region: 日本` は、第 2 回が中国での従軍を扱って区画が跨るので [ADR-0034](../adr/0034-series-vocabulary.md) の `region` の選び方の表の 2 行目に当て、人物の本拠の生地（東京）で決めた。
`@historian` は、ブリタニカ国際大百科事典の小項目事典が生地を東京とすることを確認し、生地が東京、育った地が高知で、どちらも `日本` の範囲なので `region` は揺れないとした。

`title: やなせたかし` は、シリーズ名の「ショート やなせたかし」からコーナー名を除いたものである。
`id` の `yanase-takashi` は、現物の `yoshida-shoin` に揃えて姓と名を別の語として割った。
`title` に指摘は出なかった。

## 仮決定と論点

2026-09-11 に Claude が `@historian` の結果を見て仮決定し、同日に #166 の決定（ADR-0041）で事物の `id` の理由を順 2 に揃えた。
値は変わらなかった。
2026-09-11 に人間が仮決定を採用して決着させた。

| 論点 | 仮決定 | 覆りうる根拠 |
|---|---|---|
| 事物の `id` | `shinjuku`（#166 の順 2） | 伊藤野枝の中心の場所も東京の中の一か所（青鞜社の所在地など）に絞れると見れば、順 3 で `season` の小さいやなせたかし（48）が `tokyo` を使い、伊藤野枝が移る |
| 座標の典拠 | 地図サイト（参考程度） | GeoNames か Wikidata で取り直せば格が上がる |
