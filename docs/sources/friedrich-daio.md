## 代表点

| 欄 | 値 |
|---|---|
| 典拠が示す値 | 13.0386, 52.4033（サンスーシ宮殿） |
| 典拠 | `@historian` が Wikidata と Wikipedia の座標で照合した（照合した項目の URL は報告に無い） |
| 典拠の格 | 三次 |

種別は `人物` だけなので、[ADR-0041](../adr/0041-series-vocabulary-tiebreaks.md) の「代表点と `kind` の選び方」の表の 3 行目で、活動の拠点に代表点を置いた。
サンスーシ宮殿を建てて治世の大半を過ごした地なので、ポツダムにした。
`@historian` によれば、Britannica はポツダムを没地とも記す。

プロイセンの首都はベルリンで、ADR-0041 は人物の活動の拠点に「治めた国の都」を含める。
ADR-0041 の決定（#171）により、治めた国の都と本人が暮らして執務した地が別の都市なら、暮らして執務した地を先に見るので、ベルリンでなくポツダムにした。

| 候補 | 置くと何が起きるか |
|---|---|
| ポツダム（現在値） | 王の居所と没地に寄る |
| ベルリン | 治めた国の首都に寄る。#171 の決定では暮らして執務した地を先に見るので当たらない |

## `region`・`kind`・`title`

`region: ヨーロッパ` は、プロイセンと戦ったオーストリア・ロシア・フランスがヨーロッパに収まるので、ADR-0041 の `region` の選び方の表の 1 行目で決めた。
`@historian` は、生没年が一致し、ポツダムが代表点として妥当だと確認した。
`kind: place` は表の 3 行目に当たり、自動レビューは `place` と位置なしの組み合わせに当たらないことを確認した。
`title: フリードリヒ大王` はシリーズ名のままで、指摘は出なかった。
`id` の `friedrich-daio` は、カタカナの語形に合う綴りの Friedrich に、「大王」の読みを付けた。
英語の慣用形の Frederick はカタカナの語形に合わないので使わなかった。

## 仮決定と論点
